# Parision Café Management Dashboard

A simple café management web application developed as a school project using HTML, CSS, and JavaScript. The system provides a basic interface for managing café menu items, customer orders, and café information.

## Project Information

* **Project Name:** Parision Café Management Dashboard
* **Project Type:** Frontend Web Development
* **Course Project:** Web UI Design / Web Development
* **Technologies:** HTML5, CSS3, JavaScript
* **Storage:** JavaScript arrays and objects
* **Backend:** None

## Project Description

The Parision Café Management Dashboard is designed to help café administrators manage basic café operations through a simple and user-friendly interface.

The application includes three main sections: Orders, Menu, and Settings. Users can manage menu items, create and track customer orders, and update basic café information.

This project focuses on practicing frontend development concepts, including webpage structure, styling, DOM manipulation, event handling, form processing, and array operations in JavaScript.

## Project Objectives

* To design a simple and user-friendly café management interface.
* To apply HTML and CSS in building a structured and consistent web layout.
* To use JavaScript to implement interactive functionality.
* To practice CRUD operations using arrays and objects.
* To understand event listeners, DOM manipulation, and form validation.
* To simulate basic café management operations without a backend or database.

## Features

### 1. Order Management

* Display customer orders and their details.
* Create new orders by selecting menu items and quantities.
* Calculate order totals.
* Track order status, including Pending and Completed.
* Update order status when an order is completed.

### 2. Menu Management

* Display menu items with names, categories, prices, and stock quantities.
* Add new menu items.
* Edit existing menu items.
* Delete menu items.
* Filter menu items by category.
* Update item stock when orders are placed.

### 3. Settings

* Update the café name.
* Update the administrator name.
* Save changes to the current settings.

## Installation and Usage

1. Clone or download this repository.
2. Open the project folder.
3. Ensure that the HTML, CSS, JavaScript, and image files are in their correct locations.
4. Open `index.html` in a web browser.
5. Navigate between the Orders, Menu, and Settings sections to use the application.

No additional installation, backend server, or database configuration is required.

## Data Management

The application uses JavaScript arrays and objects to store and manage its data.

For example, menu items and orders are represented as JavaScript objects inside arrays. JavaScript array methods and DOM manipulation are used to update the displayed content when users perform actions.

The project does not use a backend, database, or server-side API. Therefore, changes made during a session are not permanently saved and may be lost when the page is reloaded.

## Learning Outcomes

Through this project, the developer practices:

* Creating structured webpages using HTML.
* Applying CSS for consistent layouts and styling.
* Using JavaScript variables, functions, arrays, and objects.
* Handling user interactions with event listeners.
* Implementing Create, Read, Update, and Delete (CRUD) operations.
* Processing form input and validating user data.
* Dynamically rendering menu items and orders.
* Organizing a small frontend project into separate files.

## Limitations

* Data is stored in memory and resets when the page is reloaded.
* There is no backend or database integration.
* Authentication and role-based access control are not implemented.
* The application is intended for educational demonstration rather than production use.
